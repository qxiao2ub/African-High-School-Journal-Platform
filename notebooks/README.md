# Google Colab Notebook

**Founder / Author / Main Builder:** Kavya Kaushal Shah  
**Advisor / Mentor:** Dr. Qingyang Xiao

Open `high_school_journal_platform_colab.ipynb` in Google Colab and run the cells from top to bottom. The notebook reconstructs the UI-integrated project from an embedded compressed archive, installs dependencies, runs the service and UI tests, provides a Streamlit launch option, and creates a GitHub-ready ZIP.

The full GitHub repository remains the recommended source of truth for development and Streamlit Community Cloud deployment.
