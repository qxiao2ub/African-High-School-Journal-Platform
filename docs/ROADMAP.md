# Roadmap

**Founder / Author / Main Builder:** Kavya Kaushal Shah  
**Advisor / Mentor:** Dr. Qingyang Xiao

## MVP included in this repository

- Streamlit website with migrated journal-style UI
- official journal seal, classroom hero, and research imagery
- responsive masthead, navigation, article cards, workflow panels, and footer
- SQLite database and schema
- student manuscript upload and online editor
- local AI similarity screen
- AI reviewer matching
- reviewer assignments and structured review forms
- editor/admin publication tools
- searchable public electronic library
- CSV and publication downloads
- service smoke test
- UI integration test
- static execution test for all six Streamlit workspaces
- self-contained Google Colab notebook
- preserved React/Vite design reference

## Next technical milestones

1. Verified authentication with student, reviewer, editor, and administrator roles
2. Managed PostgreSQL database and cloud object storage
3. Transactional email invitations and status notifications
4. Multiple-reviewer decision rules and editor override logs
5. Student revision uploads with visible version comparison
6. Full-text search index and richer article metadata
7. DOI and ISSN exploration after governance is established
8. Accessibility and low-bandwidth audit
9. Production logging, backups, monitoring, and incident response
10. Licensed plagiarism or scholarly-search integration
11. Automated end-to-end browser tests in continuous integration
12. Optional multilingual support for major African and international languages

## Governance milestones

1. Formal editorial board and scope statement
2. Reviewer recruitment, verification, and training
3. Privacy, child-safety, and guardian-consent policies
4. Author publication agreement and copyright licensing choices
5. Conflict-of-interest and confidentiality process
6. Corrections, retractions, appeals, and withdrawal process
7. Research ethics standards for surveys, interviews, health data, and experiments
8. Partnerships with schools, teachers, universities, libraries, and research mentors
9. Sustainable funding and scholarship model
10. Print-edition feasibility study after the electronic journal gains traction
