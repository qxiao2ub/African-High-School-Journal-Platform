# Roadmap

## MVP included here

- Streamlit web app
- SQLite database
- Student upload and online editor
- Local AI similarity screen
- AI reviewer matching
- Reviewer portal
- Editor/admin publication tools
- Public electronic library
- Smoke test
- Colab notebook

## Next technical milestones

1. Authentication with roles and secure sessions
2. Cloud database, such as PostgreSQL or Supabase
3. Cloud file storage
4. Email invitations for reviewers
5. Multiple-reviewer decision logic
6. Full-text search index
7. DOI/ISSN exploration after governance is established
8. Accessibility audit
9. Production logging and backups
10. Licensed plagiarism/search API integration

## Governance milestones

1. Editorial board
2. Reviewer recruitment and verification
3. Privacy and child-safety policies
4. Author publication agreement
5. Conflict-of-interest process
6. Corrections and withdrawals process
7. Partnerships with schools and teachers
