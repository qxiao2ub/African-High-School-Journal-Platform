## Source code

Kavya Kaushal Shah and contributors can publish the platform code on GitHub under an open-source license. The included `LICENSE` file uses the MIT License as a simple default. Other choices include Apache-2.0 or GPL, depending on the project's goals.

## Website name and branding

The platform name, logo, and branding should be documented. If a formal trademark strategy is needed, consult a qualified professional.

## Student papers

Student authors should normally retain copyright in their own manuscripts unless they sign a clear publication agreement. The journal can request permission to publish electronically.

## Recommended publication license options

- All rights reserved by the student author, with permission for the journal to publish.
- Creative Commons Attribution, if authors want reuse with credit.
- Creative Commons Attribution-NonCommercial, if authors want noncommercial reuse with credit.

## GitHub release checklist

1. Add copyright notice in README and source files if desired.
2. Keep the LICENSE file in the repository root.
3. Add contributor guidelines before accepting outside code.
4. Keep student manuscript data out of the public GitHub repository unless authors consent.
5. Use GitHub releases for versioned source-code packages.
