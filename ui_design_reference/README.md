# Original UI Design Reference

This folder preserves the user-supplied Vite/React/TypeScript journal UI prototype that informed the Streamlit redesign.

- The launchable application is the root-level `app.py`.
- Streamlit Community Cloud does not build this reference folder.
- The relevant seal and imagery were copied into the root `assets/` folder.
- See `UI_MIGRATION_NOTES.md` for the component mapping.

The nested `react_vite_prototype/` may be developed separately with Node.js for future front-end experimentation.
